# Chrome Web Store — Lectoro AI - Language Learning & Subtitles

Last updated: 2026-09-08. Local development notes; no release submitted.

## Store listing

Name: Lectoro AI - Language Learning & Subtitles (manifest version 1.0.0).

Feature description for the next listing update:

See one concise translation per subtitle word in word-by-word mode. Hover to see alternative
translations and example sentences. Click an example to reveal its translation. Available examples and meanings depend on the downloaded language dictionary.

## Graphics

Refresh the subtitle hover screenshot to show expanded meanings, bilingual examples and
the selected meaning. Existing icon files remain unchanged.

## Permissions and privacy

This change introduces no new permissions or external service. Dictionary context matching
runs in the extension using downloaded dictionary data. It does not send sentence context
to a model provider. Existing translation, account, sync and optional AI features retain
their separate behavior. Example translations remain hidden until the user expands a sentence.

## Limitations

Context suggestions use dictionary examples and a small set of English grammar rules.
They can be wrong or unavailable. A single machine translation contains no additional
meanings or examples. This file records the feature change; publisher details, distribution,
privacy policy and the full store submission disclosures still need to be completed for publication.
